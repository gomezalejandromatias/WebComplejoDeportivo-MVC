## Brand & Style

This design system establishes a high-performance, nocturnal athletic aesthetic tailored for modern sports facility operations, field reservations, and match organization. The visual language blends tactical precision with stadium energy under floodlights: deep obsidian backdrops, sculpted charcoal surfaces, high-contrast typography, and a potent athletic crimson spark that triggers immediate action.

### Emotional Response & Personality
- **Competitive & Authoritative:** Instills immediate confidence in field quality, automated lighting, and schedule precision.
- **Electric & Nocturnal:** Captures the atmosphere of nighttime amateur tournaments, illuminated synthetic turf, and post-match camaraderie.
- **Frictionless & Decisive:** Clear visual states allow fast tactical decisions—booking a slot, verifying payment status ("Seña"), or locking rosters in seconds.

### Aesthetic Foundation
- **Modern High-Contrast Dark Mode:** Engineered around pure blacks, layered cool dark grays, and structural border division rather than heavy skeuomorphic drop shadows.
- **Tactical Precision:** Uses concise data density, technical typography, high-visibility status badges, and prominent booking grids reminiscent of professional stadium control hubs.

## Colors

The palette leverages high-contrast functional color roles built on deep, desaturated dark tones to sustain focus during nighttime mobile bookings and desk management.

### Primary Athletic Accent
- **Primary Athletic Crimson (`#E11D48`):** Reserved strictly for high-impact brand declarations, key conversions (e.g., "Reservar Cancha", "Confirmar Turno"), live badges, and active interactive borders.
- **Primary Glow / Surface Tint (`rgba(225, 29, 72, 0.12)`):** Used for hover halos and active selection chips.

### Functional Status System
- **Emerald Turf / Disponible (`#10B981`):** Indicates open time slots, confirmed payments, and active synthetic fields.
- **Amber / Seña Pendiente (`#F59E0B`):** Used for slots with pending deposit verification, warnings, and unconfirmed reservations.
- **Slate Crimson / Ocupado (`#F43F5E`):** Denotes booked slots, locked fields, and unavailable time intervals.
- **Tactical Sky / Secondary Action (`#2563EB`):** Secondary administrative tools, referee allocations, and roster details.

### Neutral Tier Hierarchy
- **Canvas Base (`#0B0E14`):** Primary viewport backdrop; minimizes battery draw and eye fatigue.
- **Surface Elevation 1 (`#141824`):** Card panels, scheduler columns, dialog wrappers.
- **Surface Elevation 2 (`#1B2234`):** Hovered cards, segmented controls, inner wells.
- **Structural Border (`#22293A`):** Low-contrast dividers and card perimeters ensuring clear geometric separation.
- **Text Primary (`#F8FAFC`):** Maximum readability for headings, match times, and prices.
- **Text Secondary (`#94A3B8`):** Subheadings, turf specs, pitch characteristics, and form labels.
- **Text Muted (`#64748B`):** Inactive indicators, table headers, metadata.

## Typography

The type system runs uniformly on **Plus Jakarta Sans**, offering a clean, contemporary grotesque appearance with geometric terminals and subtle open counters. It communicates both athletic energy and digital ergonomics.

### Rules & Formatting
- **Numbers & Times:** Match slots, currency values (`$ ARS`), and scores must be rendered using `font-variant-numeric: tabular-nums` to preserve vertical visual alignment across scheduling tables.
- **Hierarchy Anchors:** Primary section labels (e.g., `CANCHA 1 • FÚTBOL 7`) utilize `label-sm` with uppercase transformation and tracking (`+0.05em`) to evoke tactical tournament readouts.
- **Line Length Limits:** Match policy statements and terms should not exceed 68 characters per line to guarantee scanability on mobile interfaces.

## Layout & Spacing

The structural layout uses an adaptive fluid-width container anchored to a baseline 8pt spatial grid (with 4pt half-steps for micro-alignments like badge internal padding and icon margins).

### Grid Infrastructure
- **Mobile (< 768px):** 4-column layout, `margin: 1rem`, `gutter: 1rem`. Field booking grids collapse to vertically scrollable hour blocks with sticky bottom checkout trays.
- **Tablet (768px – 1023px):** 8-column layout, `margin: 1.5rem`, `gutter: 1.25rem`. Two-column field card arrangements.
- **Desktop (≥ 1024px):** 12-column layout, maximum wrapper width of `1280px`, `margin: 2.5rem`, `gutter: 1.75rem`. Matrix grid viewing multiple field schedules simultaneously.

### Spatial Hygiene
- Element clusters within cards (badge + field title + surface specs) must maintain tight rhythm using `space-xs` and `space-sm`.
- Container padding is locked to `space-md` on mobile and `space-lg` on desktop to maintain balanced density without feeling cluttered.

## Elevation & Depth

This design system deliberately minimizes standard blurred drop shadows, replacing them with sharp tonal layer boundaries and subtle inner glows that simulate athletic lighting against deep backgrounds.

### Elevation Hierarchy
1. **Floor 0 (Canvas):** `#0B0E14` (Main viewport background).
2. **Floor 1 (Surfaces):** `#141824` framed with a hairline border `1px solid #22293A`.
3. **Floor 2 (Interactive Floating Layers & Active Modals):** `#1B2234` paired with an athletic ambient tint: `box-shadow: 0 12px 32px -4px rgba(0, 0, 0, 0.7), 0 0 0 1px #2E384D`.
4. **Active Crimson Spotlight:** Active selection states, focused schedule slots, and prominent buttons project a soft crimson aura: `box-shadow: 0 0 20px -2px rgba(225, 29, 72, 0.4)`.

### Border Discipline
Every elevated layer is defined by a 1px border. Never allow dark cards to sit edge-to-edge with the base canvas without the `#22293A` structural divider.

## Shapes

The design system incorporates geometric roundedness (`0.5rem` / `8px` base) to strike an equilibrium between a technical sports application and an inviting consumer booking tool.

### Application Rules
- **Base Components (`rounded` / 8px):** Input elements, standard buttons, dropdown selectors, time-slot chips.
- **Containers (`rounded-lg` / 16px):** Field booking summary cards, calendar modules, dialog windows.
- **Pills (`rounded-full` / 9999px):** Status flags (`Confirmada`, `Seña pendiente`), turf chips (`Sintético Pro`, `Fútbol 5`), and score pill indicators.

## Components

### Buttons
- **Primary Action (Book Slot, Pay Deposit):** Crimson background (`#E11D48`), text `#FFFFFF` (`label-lg`), height `48px`, shape `8px`. Active press effect scales down to `0.98`. Focus ring: `2px solid #FFFFFF` with `2px` offset.
- **Secondary Action (Change Date, Filter Turf):** Background `#1B2234`, border `1px solid #22293A`, text `#F8FAFC`. Hover brings border to `#94A3B8`.
- **Ghost/Tertiary (Cancel, Back):** Background `transparent`, text `#94A3B8`. Hover changes text to `#FFFFFF` and background to `rgba(255, 255, 255, 0.05)`.

### Sports & Turf Badges
Compact, pill-shaped tags used for field specification and match categories:
- **Format:** Upper-case `label-sm`, height `24px`, horizontal padding `10px`.
- **Turf Variant (Sintético Pro, Techada, Césped Natural):** Background `#141824`, border `1px solid #2E384D`, text `#94A3B8`.
- **Modality Variant (Fútbol 5, 7, 11):** Background `rgba(37, 99, 235, 0.15)`, border `1px solid rgba(37, 99, 235, 0.4)`, text `#60A5FA`.

### Status Indicators
Small dot (`6px` diameter) paired with high-contrast text to signal slot availability:
- **Disponible:** Circle `#10B981` with pulsating glow `box-shadow: 0 0 8px #10B981`, label text `#10B981`.
- **Seña Pendiente:** Circle `#F59E0B`, label text `#FBBF24`.
- **Confirmada:** Circle `#E11D48`, label text `#FDA4AF`.
- **Ocupado:** Dim circle `#475569`, label text `#64748B`.

### Time-Slot Selector Grid (Turnero)
The centerpiece of the platform:
- **Card Matrix:** Interactive tiles displaying start/end hour, field number, and price.
- **Available State:** Surface `#141824`, border `1px solid #22293A`, price text `#F8FAFC`. Hover lifts to `#1B2234` with border `#E11D48`.
- **Selected State:** Border `2px solid #E11D48`, background `rgba(225, 29, 72, 0.08)`, subtle glow.
- **Disabled/Occupied State:** Surface `#0B0E14`, border `1px solid #161C28`, text `#475569`, strike-through on time label.

### Form Inputs
- **Base Input / Dropdown:** Height `48px`, background `#141824`, border `1px solid #22293A`, text `#F8FAFC`, placeholder `#475569`, padding `0 16px`.
- **Focus State:** Border changes to `#E11D48`, box-shadow `0 0 0 1px #E11D48`.
- **Prefix / Suffix Icons:** Placed at `14px` inset, color `#94A3B8`.

### Cards & Panels
- Constructed on `#141824` with `1px solid #22293A` and `rounded-lg` (16px).
- Field preview card features a top image display (16:9 aspect ratio) overlaid with a subtle linear gradient fading into the charcoal body to ensure legibility of bottom badges and hourly pricing.
